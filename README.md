Neon Shore Cover Studio — an offline web app that turns any photo and caption into multi-panel poster-style cover art with a Vice City neon-sunset grade, exported as PNG in 1080×1080, 1080×1350 and 1920×1080. Upload one or more photos, pick a layout (hero, four-panel, nine-panel, full-bleed, tilted snapshots), choose a colour grade, set the caption, and export all three post sizes in one click. Everything runs locally in the browser; photos never leave the machine.

## Run it

```sh
python3 -m http.server 8080 --directory app
```

Then open http://localhost:8080 in a desktop browser.
